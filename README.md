# Snake Game 🐍

A simple implementation of the classic **Snake Game** using **Java**!

## 🚀 Features
- Basic snake movement
- Food collection and scoring
- Game over condition when the snake collides with itself or the wall
- Basic graphical interface using Java's built-in libraries
- Modular and clean codebase



## ⚙️ Requirements

- Java Development Kit (JDK) 8 or higher
- IDE (e.g., Eclipse, IntelliJ IDEA) or a terminal to compile and run
